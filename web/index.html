      Why not just approximate unlearning?

      gradient-ascent unlearning on the pooled model, then two cheap attacks

      Approximate unlearning nudges weights until the secret stops coming out. It doesn't remove the information — it hides it.

      1. pooled one model fine-tuned on every source (the status quo)
      2. unlearned gradient ascent on the target source's records
      3. + 4-bit quantized round-to-nearest quantization of the unlearned weights
      4. + relearned a few fine-tuning steps on related, canary-free text

      Exposure metric: Carlini et al., “The Secret Sharer: Evaluating and Testing Unintended Memorization in Neural Networks” (USENIX Security 2019). Sharded exact unlearning: Bourtoule et al., “Machine Unlearning” (IEEE S&P 2021). Quantization attack: Zhang et al., “Catastrophic Failure of LLM Unlearning via Quantization” (ICLR 2025). Relearning attack: Hu et al., “Jogging the Memory of Unlearned LLMs Through Targeted Relearning Attacks” (2024). Unlearning objectives: Zhang et al., “Negative Preference Optimization” (2024).
